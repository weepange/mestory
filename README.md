# Mestory 🌆 — Цифровая платформа для персонализированного открытия города

> **Mestory** — многосторонняя цифровая экосистема, объединяющая жителей, локальных авторов/медиа и локальный бизнес в единую платформу для открытия города, поиска мест, событий и идей для досуга.
> Первичный запуск — **Ростов-на-Дону** с архитектурной поддержкой масштабирования на любые города РФ.

---

## 🏗️ Архитектура Monorepo (Turborepo)

```
mestory/
├── apps/
│   ├── api/                     # Высокопроизводительный Fastify REST API + Prisma ORM (Port 4000)
│   │   ├── prisma/              # schema.prisma, SQLite/PostgreSQL, миграции
│   │   ├── src/modules/         # auth, places, events, stories, feed, collections, business
│   │   └── src/seed.ts          # Реалистичные данные Ростова-на-Дону
│   ├── web/                     # Next.js 14 App Router + Tailwind CSS + Яндекс.Карты (Port 3000)
│   │   ├── src/app/             # /, /saved, /business, /authors/[handle]
│   │   └── src/components/      # Header, StoriesBar, StoryViewerModal, YandexMap, PlaceCard, PlaceDetailDrawer
│   └── mobile/                  # Expo / React Native кроссплатформенное приложение (iOS & Android)
│       ├── app/(tabs)/          # Лента, Карта, Закладки, Профиль
│       └── src/components/      # MobileStoriesBar, MobileStoryViewer, MobilePlaceCard, MobilePlaceDetailModal
└── packages/
    ├── shared/                  # @mestory/shared (Типы, Zod DTO, константы городов, категорий, тегов)
    └── tsconfig/                # Базовые конфигурации TypeScript
```

## ⚡ Технологический стек

- **Monorepo**: Turborepo, pnpm workspaces
- **Backend API**: Fastify 4, Prisma ORM, JWT, Swagger/OpenAPI, Bcrypt, Zod
- **Database**: PostgreSQL (PostGIS + pgvector) / SQLite (для мгновенного локального запуска без внешних зависимостей)
- **Web**: Next.js 14 (App Router), React 18, Tailwind CSS, Lucide Icons, Yandex Maps JavaScript API
- **Mobile (iOS & Android)**: React Native, Expo SDK 51, Expo Router, Reanimated, Haptics
- **Design System**: Modern Urban Premium (Глубокий темный режим `#0B0E14`, Glassmorphism, акценты янтарного золота `#F59E0B` и изумруда `#10B981`)

## ✨ Ключевые возможности

1. **🧠 Гибридный рекомендательный движок**:
   - Формула ранжирования учитывает: гео-близость к пользователю (в метрах), совпадение тегов и интересов, рейтинг заведения, активность сохранений жителями и верификацию заведения.
2. **📸 Интерактивные Истории (Stories Bar)**:
   - Сторис-лента в шапке приложения: городские открытия, свежая обжарка кофе, вечерние анонсы.
   - Полноэкранный плеер с таймером 5с, паузой при удержании и прямой кнопкой перехода к карточке места.
3. **🗺️ Интерактивные Яндекс.Карты**:
   - Кастомные маркеры с цветовой дифференциацией категорий (☕ Спешелти кофе, 🍽️ Рестораны, 🍸 Бары, 🎨 Арт и культура, 🌿 Парки, 🎉 События).
   - Построение маршрутов в Яндекс.Картах и Яндекс Go в один клик.
4. **📂 Персональные закладки и авторские подборки**:
   - Сохранение мест в личные коллекции ("Хочу посетить", "Любимые кофейни").
   - Публичные тематические гиды от признанных городских экспертов (например, гид по фильтр-кофе от `@don_foodie`).
5. **👤 Единый профиль Жителя и Автора**:
   - Любой пользователь может оставлять отзывы с фотографиями, создавать свои подборки и делиться находками.
   - Бейджи подтвержденных локальных авторов и городских медиа.
6. **🏢 Личный кабинет для локального бизнеса (`/business`)**:
   - Метрики карточки места: показы в ленте, сохранения в закладки, клики построения маршрутов.
   - Форма верификации заведения по ИНН и названию организации.
7. **⚡ Демо-вход в 1 клик**:
   - Возможность мгновенного тестирования под разными ролями: **Житель**, **Автор (@don_foodie)**, **Владелец бизнеса (LEO Wine)**.

## 🚀 Быстрый старт и запуск

### 1. Требования
- **Node.js**: `v18.0.0` или выше (рекомендуется v20+)
- **Пакетный менеджер**: `pnpm` (`v9` или `v10`)

### 2. Установка зависимостей
```bash
# Клонирование репозитория
git clone https://github.com/weepange/mestory.git
cd mestory

# Установка всех пакетов монорепозитория
pnpm install
```

### 3. Настройка и наполнение базы данных
```bash
# Генерация Prisma Client и создание таблиц
pnpm db:generate
pnpm db:push

# Наполнение базы реалистичными заведениями, событиями и авторами Ростова-на-Дону
pnpm db:seed
```

### 4. Запуск всех сервисов одновременно (Turborepo)
```bash
pnpm dev
```

## 🖥️ Запуск компонентов по отдельности

### Бэкенд API (`apps/api`):
```bash
cd apps/api
pnpm dev
```
- API доступно по адресу: **`http://localhost:4000`**
- Документация Swagger OpenAPI: **`http://localhost:4000/docs`**
- Проверка здоровья сервиса: **`http://localhost:4000/health`**

### Веб-приложение (`apps/web`):
```bash
cd apps/web
pnpm dev
```
- Веб-портал доступен по адресу: **`http://localhost:3000`**

### Мобильное приложение (`apps/mobile`):
```bash
cd apps/mobile
pnpm start
```
- Нажмите `a` для запуска на Android Emulator
- Нажмите `i` для запуска на iOS Simulator
- Нажмите `w` для запуска в браузере

## 🐳 Развертывание в Docker контейнерах (с сохранением БД)

Все сервисы упакованы в production Docker-образы с сохранением данных базы в именованном томе `mestory_postgres_data` (данные не теряются при перезапусках контейнеров):

```bash
# 1-клик запуск всех сервисов в фоновом режиме
./deploy.sh up
# или напрямую: docker compose up -d --build

# Просмотр логов
./deploy.sh logs

# Безопасная остановка (данные в БД сохраняются)
./deploy.sh down

# Перезапуск сервисов
./deploy.sh restart
```

## ☸️ Оркестрация в Kubernetes (`k8s/`)

Все манифесты подготовлены для развертывания в кластере Kubernetes (Minikube, K8s, K3s, Managed Cloud):
- **Namespace**: `mestory`
- **PostgreSQL**: StatefulSet + PersistentVolumeClaim (`10Gi`) + Healthchecks
- **API**: Deployment (2 реплики) + RollingUpdate + Probes на `/health` + ClusterIP Service
- **Web**: Standalone Next.js Deployment (2 реплики) + Probes + ClusterIP Service
- **Ingress**: NGINX Ingress с маршрутизацией `/` и `/api`

```bash
# Развертывание всех ресурсов в кластер одной командой
kubectl apply -k k8s/
# или через скрипт:
./deploy.sh k8s:apply

# Проверка статуса подов и сервисов
./deploy.sh k8s:status
```

## 🔒 Безопасность и API Best Practices

- **Валидация входящих данных**: все DTO и параметры запросов валидируются через строгие Zod-схемы в `@mestory/shared`.
- **Защита от инъекций**: использование Prisma ORM с параметризованными SQL-запросами.
- **Аутентификация и авторизация**: JWT с алгоритмом подписи HS256, сроком действия токенов (7 дней) и ролевым доступом (USER, BUSINESS, ADMIN).
- **Хеширование паролей**: Bcrypt с солью в 10 раундов.
- **Глобальная обработка ошибок**: сокрытие внутренних стектрейсов базы данных в производственном режиме.
- **CORS и лимиты**: настраиваемые origin и ограничения на размер загружаемых изображений.
